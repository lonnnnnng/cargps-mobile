# CarGPS v0.1.1

此版本最初在项目拆分前以双端形式发布。本次补丁重点优化手机版单屏仪表的信息密度与中文可读性。

## 手机版

- 针对 `Pixel_9` 重新分配纵向空间，全部实时信息、最近行程和操作按钮无需滚动即可完整显示。
- 主速度与当前行程区域固定为紧凑高度，避免停车或无数据状态出现大面积空白。
- 放宽统计、定位遥测、最近行程和操作区域，改善原先上松下挤的问题。
- 年月日时分秒在右上角同一行完整显示。
- 经纬度增加中文标签，PDOP、HDOP、VDOP 和 NMEA 分别显示为位置因子、水平因子、垂直因子和报文类型。
- 最近 3 条本地行程在空闲态和记录中状态下均保持完整可见。

## 核心能力

- 拆分基线最低支持 Android 8.1 / API 27，不依赖 Google Play Services。
- 保留活动行程恢复、SQLite 本地持久化、定位质量门和 NMEA 诊断能力。

## 安装包

- `CarGPS-Mobile-v0.1.1.apk`：手机版，包名 `com.cargps.mobile`。
